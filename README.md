# MediAssist AI

MediAssist AI is an educational medical report analysis system that uses
document processing, Retrieval-Augmented Generation (RAG), and
open-source AI models to explain medical report findings in
patient-friendly language.

## Project Status

🚧 Under Development

## Core Goals

- Medical report PDF/image processing
- Medical parameter extraction
- Abnormal finding identification
- Evidence-grounded RAG
- Patient-friendly explanations
- General health and dietary guidance
- Specialist-category recommendation
- Nearby healthcare facility search
- Downloadable medical report summary

## Disclaimer

MediAssist AI is an educational and informational system.
It does not provide medical diagnosis or replace professional
medical advice.
